# ============================================================================
#  FULL SIGNAL SWEEP TEST
#  Each block pulses a signal 10x, 100 ms ON / 100 ms OFF.
#
#  Part 1 : every ECU, each of its 3 signals individually (ECU1..ECU4).
#  Part 2 : all ECUs together -- all BATs, then all ACCs, then all IGNs.
#  Part 3 : absolutely everything together (ON ALL / OFF ALL).
#
#  The ESP32 does NOT run this file -- the PC streams the commands with
#  the right timing. Load it with the  R-U-N  SCRIPT  button.
# ============================================================================

# ---------------------------------------------------------------------------
# PART 1 -- individual signals, one ECU at a time
# ---------------------------------------------------------------------------

# ECU1 -- BAT  (10x)
LOOP 10
    ECU1_BAT ON
    DELAY 100
    ECU1_BAT OFF
    DELAY 100
ENDLOOP
